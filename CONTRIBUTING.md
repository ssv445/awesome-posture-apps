# Contributing

Thanks for helping keep this list right. Open a pull request to add an app or fix a fact.

## Add an app

1. It must help people with their posture at a computer, and you must be able to get it today.
2. Put it in the group that matches how it notices your posture: webcam, AirPods or headphones, wearable, break timer, or browser-based.
3. Keep the group in alphabetical order.
4. Write one line in the same shape as the others: the name linked to the maker's site, one sentence on what it uses and how it nudges you, where it runs, and the price model (free, paid once or subscription).
5. If the code is public, add "Open source" with the repo link, and add it to the Open source section too.
6. In the pull request, link the maker's page for every fact in your line.

## Fix a fact

1. Change the line.
2. In the pull request, link the maker's page that shows the new fact.

## Rules

1. Facts come only from the maker's own website or store listing. Reviews, forums and other lists don't count.
2. No ranking and no "best". Plain facts only.
3. No health or medical claims.
4. An app that is no longer made stays on the list, marked "No longer made".

I check each pull request against the maker's page before I merge it. Not sure about something? Open an issue first.
